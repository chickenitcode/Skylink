# PROJECT REPORTS (reports/)

Thư mục này dành riêng cho việc lưu trữ các báo cáo chính thức, hồ sơ bàn giao và kết quả kiểm thử trong suốt quá trình triển khai dự án:

### 1. Phân loại báo cáo:
- **Báo cáo tiến độ (Milestone / Daily Standup Reports)**: Theo dõi tiến độ hoàn thành các đầu việc D1-1 đến D7-6 theo từng ngày.
- **Báo cáo kiểm thử & chất lượng (QA / Test Evaluation Reports)**: Kết quả chạy integration test, golden set AI eval, đo lường độ chính xác retrieval, matching, latency.
- **Hồ sơ nghiệm thu & Bàn giao (Release Notes & Handover)**: Biên bản checkpoint Go/No-Go cuối ngày và tài liệu phát hành MVP v0.1.
